✨ Custom Modal System

Beautiful, animated modals with no dependencies

📝 Prompt Modals

Get user input with beautiful, animated prompt dialogs. Perfect for collecting names, reasons, or any text input.

const value = await ModalUtils.showPrompt( 'Enter your name:', 'User Input', 'John Doe' );

✅ Confirm Modals

Get user confirmation with styled dialogs. Different types for different actions.

const confirmed = await ModalUtils.showConfirm( 'Are you sure?', 'Confirm Action', 'Confirm', 'danger' );

🔔 Alert Modals

Show important messages with color-coded alerts. Perfect for success, error, warning, and info messages.

await ModalUtils.showAlert( 'Operation completed!', 'Success', 'success' );

🍞 Toast Notifications

Show non-intrusive notifications that auto-dismiss. Perfect for quick feedback.

ModalUtils.showToast( 'Changes saved!', 'success', 5000 );
